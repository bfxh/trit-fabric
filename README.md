# trit-fabric — 三值状态机 AI（Fabric mod）

Minecraft **26.3** + Fabric Loader **0.20.1** 的客户端 mod。
把 AI 决策（Kleene K3 三值状态机）整个搬进游戏进程里跑，不再是外部程序按仿真按键。

适用整合包：`E:\MC\MC\profiles\26.3-Fabric 0.20.1 (1)`

## 和之前的方案有什么区别

| | 旧方案（Rust 外部进程 + 数据包） | 本方案（Fabric mod） |
|---|---|---|
| 感知 | 数据包写进计分板 → 日志 → 文本解析 | 直接读游戏世界，连续值、零延迟 |
| 操控 | `SendInput` 伪造物理按键，需要窗口焦点 | 直接写 `player.input` 和 `gameMode` |
| 崩溃残留 | 进程被杀会留下卡住的按下状态 | 没有外部进程，不存在这个问题 |
| 依赖 | 开机自启 + 计划任务 + 命名互斥量 | 跟着游戏启停，没有额外服务 |
| 精度 | 8 方向 × 3 档距离的量化 | 真实距离和角度 |

状态机逻辑本身（三值、投票、裁决、迟滞）两边**完全一致**，是从 `bfxh/trit-mc`
的 `fsm.rs` / `trit.rs` 逐条移植过来的，共用同一套单元测试。

## 维护说明（默认维护 mod，数据包不干）

本项目**默认只维护 Fabric mod 形态**。之前的「Rust 外部进程 + 数据包」形态**不再维护**
——它的决策精度、对游戏版本的强依赖、以及外部进程崩溃后残留的卡键问题，都比 mod 形态差，所以被取代。

- 想直接用：装 `build/out/trit-0.1.0.jar` + Fabric API 进 `mods/` 即可。
- 想自己搞数据包版：**欢迎，但有高手你搞吧** —— 仓库不再提供维护与支持，相关 PR 也大概率不会优先 review。
- 下面的玩法、模式、热键都指 mod 形态。

## 按键

| 键 | 作用 |
|---|---|
| **Y** | 打开「环盘菜单」选主动模式（巡逻 / 采集 / 战斗 / 建造 / 跟随 / 交还）；菜单内 **Y / 回车** 确认，**← →** 选择，退格取消，数字键 **1–6** 直达 |
| **F9** | 急停（立刻松手并交还控制权） |
| **F10** | 视角控制开关 |
| **F6** | 攻击开关 |
| **F7** | 移动开关 |
| **F8** | 摄像头预算档位循环：不还视角 → 微调(±15°) → 跟踪(±45°) → 自由 |

热键在游戏里的 `选项 → 控制 → TriT 状态机` 分类下可以改。

环盘菜单是 **HUD 叠层、不暂停游戏**：打开期间世界照常跑，你也能照常操作；选完模式关掉立刻生效。

接管后屏幕上方（物品栏之上）会显示一行状态，例如：

```
[TRIT] <for> 交战 engage |+0+000- | hp80% +威胁 d2.4 x1 镜一/档2 | 有威胁
[TRIT] <for> 待命 idle |+0-0000- | hp100% -威胁 镜一/档1 !弹arrow tti9 cpa0.4/带1.1 | 没威胁
```

格式是 `模式 | 阶段 | 十个通道的方向 | 感知摘要 | 判定理由`（`<for>` 是当前模式代号）。
第二行是有 A 级弹幕来袭：它**转头也没有**，那串 `!弹arrow …` 是内部算完直接躲的读数。

另外 HUD 角上常驻两行小字（不暂停、不抢焦点）：

- 左上：`镜三后 · 预算微调 · 归你` —— 现在是第几视角、AI 有多少镜头预算、本拍它到底动了没有。
- 左下：`弹3 A2 arrow tti8 cpa0.3/带1.2 σ0.08`，同时准星外圈画一道红痕指来袭方位（**方位是算出来的，不用转头去看**）。

## 主动模式（环盘菜单）

按 **Y** 打开环盘菜单，选 AI「总体该干什么」。注意：模式和状态机的**瞬时阶段**（交战 / 撤退等）
是两回事 —— 无论什么模式，遇到威胁都会自动转入战斗 / 自保，模式只决定「没事干的时候主动去干嘛」。

| 模式 | 干啥 |
|---|---|
| 交还 (OFF) | 不主动做任何事，控制权全在你手里（但仍会在有威胁时自保） |
| 巡逻 (PATROL) | 到处走、遇墙绕、遇坑跳、卡住会自己解 |
| 采集 (FORAGE) | 主动找最近的树 / 矿走过去挖（只在这个模式主动挖，不和你抢控制权） |
| 战斗 (COMBAT) | 主动猎杀敌对生物；按距离用剑/斧近战或拉弓/弩远程（自动蓄力击发、边走位边放风筝），绕圈不站桩，并对移动目标带提前量瞄准 |
| 建造 (BUILD) | 前方是坑 / 液体就放方块搭桥 / 填坑（只在这个模式主动铺路） |
| 跟随 (FOLLOW) | 跟随指定目标：环盘选 FOLLOW 时若准星指着某人/生物就锁它，否则跟最近的玩家；保持距离跟着走，自保优先 |

切换模式随时可以，不会打断当前正在做的事。

## 它会干什么（能力清单）

- **用武器**：近战自动选剑 / 斧；距离拉开（>5 格）且有弓 / 弩 + 箭就切远程，把使用键**按住蓄力**直到蓄满再松手击发，期间边向后走位放风筝（不是站桩蹲着）；对移动目标带**提前量瞄准**（按目标速度外推落点）。
- **蹲下 / 隐藏**：只在**崖边**蹲下防被推下去；有威胁但还没交战、且不在近战距离时才会蹲伏降低存在感——交战中改走位 / 后退，不再用蹲当主自保。
- **建造 / 填坑**：建造模式下前方是坑就放一格方块搭桥，别掉下去。
- **视角即感知范围**：敌人 / 资源搜索半径跟着你的**渲染距离**走（屏幕多大它能看到多大，按你的镜头来），不写死一个定值。
- **弹幕：不看、不找、不说，内部算完直接躲**。读弹射物的位置 + 速度，按类型逐拍外推走向
  （直线 / 抛物线两档），算出**最近接近点 CPA** 和**命中时间 TTI**；判据是
  「算出来的 CPA」对比「**预测**出来的波动带」—— 客户端读不到真实重力和阻力（`getAirDrag()`
  等在 26.3 是 protected），所以每类弹在线学：系统偏差、随机波动 σ、重力修正、阻力修正。
  A 级（朝我来、TTI<2s、命中点在一个波动带内、不会被墙先挡）直接投**躲避票**（横移 / 后退 / 跳），
  权重压过巡逻、压不过脚下岩浆和低血撤退；B 级零票。全程**不转视角、不锁目标、不播报**，
  躲完自动接回原来的活。潜影贝那种会转弯的弹，学出来的 σ 会很大 —— 这正是设计：算不准就承认不确定。
- **摄像头预算：AI 自己选择调与不调，但受限**。每拍视角写入都要过档位闸门
  （不还视角 / ±15° / ±45° / 自由，F8 循环），锚定在你的视角上：
  **你转镜头，它跟着重算预算，绝不跟你抢方向盘**；AI 用完自己还（归还速率 ≤2°/拍）。
  待命扫视在低档位下改走**独立指针**（AI 自己的准星），真实镜头一动不动。
  弹幕扎堆且档位允许时，它会自己「一调三」切到第三人称背后看清大概范围，60 拍后换回第一人称；
  你手动按过 F5，它立刻放弃借用。
- **遮挡绕行**：采集 / 战斗目标被墙挡住视线时，不再傻站着硬挖硬射，而是接近或绕到能下手的角。
- **树挖完不卡**：每拍校验采集目标是否还在；挖掉了立刻失效并重扫，不会对着空气硬挖。
- **不干扰你操作（硬保证）**：只要你按了移动 / 攻击 / 使用键、正在破坏方块，AI 立刻**全部让权**（松开输入、不抢控制权）。
  打开原生界面（背包 / 聊天 / 任务栏…）时只**锁住镜头与动作**，AI 决策循环照常跑、该躲的仍躲，关掉界面立刻接管——不会因为你开了个背包就变成木头人。
- **灵性**：没事干不会当木桩 —— 会转头扫视（余光也扫威胁、不卡在视角死角）、低血且吃饱了会站桩回血、饿了会找吃的；待命时会用最近路线离开死角，不往角落死盯。

## 架构

```
com.bfxh.trit
├── core/        纯逻辑，不依赖 Minecraft
│   ├── Tri         K3 三值：未知参与运算时不猜
│   ├── Channel     10 个裁决通道（前后/左右/视角/俯仰/攻击/跳跃/使用/蹲下/远程/放置）
│   ├── Vote        行为模块投的票（方向 + 权重 + 是否按住）
│   ├── WorldView   感知快照，每个字段都允许「未知」（含弹幕与视角指标）
│   ├── Machine     阶段机 + 单通道裁决器（迟滞 + 弃权）
│   ├── Angles      朝向差计算
│   ├── CameraBudget 摄像头预算闸门（档位 / 锚点 / 夹幅 / 归还）
│   └── Mode        环盘菜单选出的主动模式（OFF/巡逻/采集/战斗/建造/跟随）
├── neo/         神经符号那一半，同样是纯 Java 零依赖、离线可测
│   ├── Ballistics          纯算弹道：逐拍积分 → CPA / TTI
│   ├── ProjectilePredictor 算 + 预测：按类型学偏差 / σ / 重力 / 阻力 + 躲避先验
│   ├── Neuron              微型感知机（3~8 输入，无反向传播）
│   ├── LearningAutomaton   奖励/惩罚在线调权（Tsetlin 风格）
│   ├── VectorKB            经验向量库 + 余弦召回
│   ├── Affinity            多轴好感度（友善/敬畏/尊重/信任）
│   └── AiPointer           AI 的独立指针（自己的准星，不碰玩家鼠标）
├── sense/Sensor    从游戏世界读感知（带性能预算和缓存；含玩家操作/遮挡/装备/地形/弹幕检测）
├── act/
│   ├── AiInput     替换 player.input 的输入源
│   └── Actuator    把裁决写进游戏（武器切换/拉弓/放方块…；视角统一过摄像头预算）
├── behave/         行为模块：巡逻 / 交战 / 撤退 / 避险 / 躲弹幕 / 采集 / 进食 / 回血 / 静息扫视 / 隐藏 / 建造 / 锚点 / 卡住挖掘 / 跟随
├── TritMod         入口：注册热键 + 每拍驱动 + 跟踪原生界面 + 维护独立指针与机位借用
└── TritHud         HUD 叠层画环盘菜单、视角归属徽标、来袭方位刻痕（26.3 用 HudElement 抽取模型，不暂停游戏）
```

**26.3 适配要点**（和 1.20.x 的 Fabric mod 写法差异很大）：

- 菜单不用会暂停游戏的 `Screen`（26.3 的 Screen 渲染模型大改），改用 `HudElement`
  抽取模型 `extractRenderState(GuiGraphicsExtractor, DeltaTracker)` 画在 HUD 上，天然不暂停。
- 「你在开背包 / 聊天 / 任务栏」用 Fabric `ScreenEvents` 检测，检测到只**锁住镜头与动作**（AI 决策循环照常跑），不锁决策——关掉界面立刻接管。
- 武器判定用 `ItemTags`（SWORDS / AXES / PICKAXES / SHOVELS / HOES）和 `BowItem` / `CrossbowItem`，
  因为 26.3 移除了 `SwordItem` / `AxeItem` / `PickaxeItem` 这类物品子类。

一拍的流程：

```
感知 → peek 阶段 → 各模块独立投票 → 裁决 → 执行 → 显示状态
```

**「不猜」是硬约束**：裁决器里未知票的权重一旦压过已知票，这一拍就弃权（松手），
绝不把「不知道」当成「没有」。AI 撞墙、无视看不见的敌人，基本都是这条规则被破坏导致的。

## 构建

不用 Gradle —— 整个工程只依赖 MC 本体和 Fabric API，javac 直接编就够，
省掉 Gradle + Loom 几十分钟的下载和映射处理。

```bash
python build.py            # 编译 + 打包 + 装进整合包
python build.py --no-copy  # 只编译打包
python test.py             # 状态机内核自检（不需要 MC）
```

编译用的是游戏自带的 JDK 25（`meta/java_versions/mojang-java-runtime-epsilon`）。
**必须用 JDK 25**：MC 26.3 的 class 是 major 69，JDK 21 的 javac 读不了。
Fabric API 缺失时 `build.py` 会自己去 Modrinth 拉 26.3 的版本。

产出：`build/out/trit-0.1.0.jar`，直接扔进 `mods/`。
Fabric API 是硬依赖，脚本会一并放进 `mods/`。

## 自检

`python test.py` 跑 **161 项**（内核 59 + 行为仿真 36 + neo 层 66），覆盖：

- K3 真值表：`not` 对合、De Morgan、未知不被猜成「是」
- 朝向差的符号约定（搞反会导致朝反方向转）
- 状态机：停机、未知压制、迟滞防抖、通道禁用、低血撤退、死亡重生、未知威胁不交战
- 交手记录把「未知威胁」抬成「有威胁」
- `peek` 与 `step` 结果一致
- 弹道（算）：直线 TTI 逐拍对上、重力是累加的、平行弹 CPA≈5 且打不到、远离的弹判 `closing=false`、
  入参数组不被外推改写、波动带随距离变宽
- 预测（学）：正对来的弹判 A 级并给出方向、**没扫描判未知而不是「没有」**、隔墙降为 B 级、
  平行飞过零响应、常数表错 0.06 时学到的重力修正方向正确且被夹在上限内、
  残余误差撑开波动带、A 级弹消失=奖励当时躲的方向、躲了仍挨打=惩罚且不许翻案、弹幕海跟踪封顶
- 摄像头预算：关档一个度都写不了、到顶就夹并记账、**玩家转镜头会把锚点带走（预算重新起算）**、
  AI 自己写的量不混进锚点、归还速率 ≤2°/拍、死区内不停抖、低档位禁自由扫视与借机位

行为仿真（`SimTest`）不进游戏，直接喂构造好的感知快照，检查典型场景下 AI 会做什么：
巡逻会走、看到树会走过去、贴着树会站住按住左键挖、4 格外的敌人只接近不出手、
2 格内会打且是脉冲不是按住、残血会退、墙前不顶、岩浆旁避险压过巡逻、饿了会吃；
A 级弹幕来袭时**横移但 YAW/PITCH 是零票**、贴脸弹额外加一跳、B 级弹完全静默、
没扫描时不因弹幕动、躲避期间采集票仍在（躲完继续走向树）、玩家接管那拍状态机全部松手。
这类测试专门防「票权和迟滞配错导致某个通道永远停在 0」—— 每一条票单独看都对，
但合起来 AI 就是站着不动，光读代码发现不了。

## 排查

启动过一次之后跑：

```bash
python diagnose.py
```

会列出 `mods/` 里每个 jar 的结构（有没有 `fabric.mod.json`、多少 class），
并从日志里挑出 trit / fabric / 报错相关的行。日志找不到会提示候选路径。
