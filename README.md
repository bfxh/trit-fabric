# trit-fabric — 三值状态机 AI（Fabric mod）

Minecraft **26.3** + Fabric Loader **0.20.1** 的客户端 mod。
把 AI 决策（Kleene K3 三值状态机）整个搬进游戏进程里跑，不再是外部程序按仿真按键。

适用整合包：`E:\MC\MC\profiles\26.3-Fabric 0.20.1 (1)`

## 和之前的方案有什么区别

| | 旧方案（Rust 外部进程 + 数据包） | 本方案（Fabric mod） |
|---|---|---|
| 感知 | 数据包写进计分板 → 日志 → 文本解析 | 直接读游戏世界，连续值、零延迟 |
| 操控 | `SendInput` 伪造物理按键，需要窗口焦点 | 直接写 `player.input` 和 `gameMode` |
| 崩溃残留 | 进程被杀会留下卡住的按下状态 | 没有外部进程，不存在这个问题 |
| 依赖 | 开机自启 + 计划任务 + 命名互斥量 | 跟着游戏启停，没有额外服务 |
| 精度 | 8 方向 × 3 档距离的量化 | 真实距离和角度 |

状态机逻辑本身（三值、投票、裁决、迟滞）两边**完全一致**，是从 `bfxh/trit-agent`
的 `fsm.rs` / `trit.rs` 逐条移植过来的，共用同一套单元测试。

## 按键

| 键 | 作用 |
|---|---|
| **F8** | 接管 / 交还 |
| **F9** | 急停（立刻松手并交还） |
| **F10** | 视角控制开关 |
| **F6** | 攻击开关 |
| **F7** | 移动开关 |

热键在游戏里的 `选项 → 控制 → TriT 状态机` 分类下可以改。

接管后屏幕上方（物品栏之上）会显示一行状态，例如：

```
[TRIT] 交战 engage|+0+000- | hp80% +威胁 d2.4 x1 | 有威胁
```

格式是 `阶段 | 七个通道的方向 | 感知摘要 | 判定理由`。

## 架构

```
com.bfxh.trit
├── core/        纯逻辑，不依赖 Minecraft
│   ├── Tri         K3 三值：未知参与运算时不猜
│   ├── Channel     7 个裁决通道（前后/左右/视角/俯仰/攻击/跳跃/使用）
│   ├── Vote        行为模块投的票（方向 + 权重 + 是否按住）
│   ├── WorldView   感知快照，每个字段都允许「未知」
│   ├── Machine     阶段机 + 单通道裁决器（迟滞 + 弃权）
│   └── Angles      朝向差计算
├── sense/Sensor    从游戏世界读感知（带性能预算和缓存）
├── act/
│   ├── AiInput     替换 player.input 的输入源
│   └── Actuator    把裁决写进游戏
├── behave/         行为模块：巡逻 / 交战 / 撤退 / 避险 / 采集 / 进食 / 回血 / 锚点
└── TritMod         入口：注册热键 + 每拍驱动
```

一拍的流程：

```
感知 → peek 阶段 → 各模块独立投票 → 裁决 → 执行 → 显示状态
```

**「不猜」是硬约束**：裁决器里未知票的权重一旦压过已知票，这一拍就弃权（松手），
绝不把「不知道」当成「没有」。AI 撞墙、无视看不见的敌人，基本都是这条规则被破坏导致的。

## 构建

不用 Gradle —— 整个工程只依赖 MC 本体和 Fabric API，javac 直接编就够，
省掉 Gradle + Loom 几十分钟的下载和映射处理。

```bash
python build.py            # 编译 + 打包 + 装进整合包
python build.py --no-copy  # 只编译打包
python test.py             # 状态机内核自检（不需要 MC）
```

编译用的是游戏自带的 JDK 25（`meta/java_versions/mojang-java-runtime-epsilon`）。
**必须用 JDK 25**：MC 26.3 的 class 是 major 69，JDK 21 的 javac 读不了。
Fabric API 缺失时 `build.py` 会自己去 Modrinth 拉 26.3 的版本。

产出：`build/out/trit-0.1.0.jar`，直接扔进 `mods/`。
Fabric API 是硬依赖，脚本会一并放进 `mods/`。

## 自检

`python test.py` 跑 59 项，覆盖：

- K3 真值表：`not` 对合、De Morgan、未知不被猜成「是」
- 朝向差的符号约定（搞反会导致朝反方向转）
- 状态机：停机、未知压制、迟滞防抖、通道禁用、低血撤退、死亡重生、未知威胁不交战
- 交手记录把「未知威胁」抬成「有威胁」
- `peek` 与 `step` 结果一致
