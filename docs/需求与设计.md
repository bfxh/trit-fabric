# trit-fabric 需求与设计文档

> 版本 v2 · 2026-11-03 · 状态：**需求冻结，实现排期中**
>
> 本文档汇总用户对 trit-fabric（MC 26.3 三值状态机 AI mod）的全部新要求，逐条带
> **验收标准**。原则：先文档后代码 —— 实现排期以本文档为唯一依据。

## 0. 一句话总纲

把现在的「三值状态机」升级成**神经符号混合系统**：状态机管时序与安全（符号层），
一批微型神经元管软感知与自适应（神经层），向量知识库与多轴好感度管经验与社交
（记忆层）。全部**零成本**：无 GPU、无在线训练、无云端、无 LLM，单拍微秒级。

## 1. 硬约束（用户拍板，不可违反）

1. **零成本**：不管动作多细，运行时开销必须 ≈ 0。不加依赖、不训练、不掉帧。
2. **不要「离谱 LLM」**：任何需要联网 / 大模型的方案都不要。
3. **最强最聪明**：不拘泥于状态机教条，用最优的方式；不同性质的东西要**分类处理**
   （适合状态机的进状态机，适合记忆的进向量库，适合软打分的进神经元）。
4. **不打扰**：摄像头默认永远归玩家；AI 的思考绝不抢玩家的鼠标、键盘、视角。
5. **可测试**：每条需求都有可自动化的验收标准；测试场景要**大量**，可观测指标要**大量**。

## 2. 调研结论（论文 / 先例 → 落地决策）

| 调研对象 | 核心结论 | 落地决策 |
|---|---|---|
| Neuro-Symbolic Generative Agents (arXiv 2402.16905) | 自动机管时序与保证，神经管内容 | 状态机继续管时序与安全；微神经元只做「软打分」 |
| NeSy-MMs / BlendRL / NS-CSG (2024) | 神经+符号混合优于任何单边；按步分解可扩展 | 保持每拍「投票→裁决」分解，神经信号作为票源之一 |
| Playing Atari with Six Neurons (IJCAI 2020) | 感知与决策解耦后，策略层 6~18 个神经元就够 | 「很多小神经元」= 每行为一个 3~8 输入微感知机，完全可行 |
| Tsetlin Machine / DLGN (2018~2026) | 无反向传播：奖励/惩罚符号级更新，推理纳秒级 | `LearningAutomaton`：在线 reward/penalty 调权，O(n)/拍 |
| Freecam mod (Fabric) | 摄像头可与玩家完全解耦 | 独立指针 `AiPointer` 可行：AI 自有视角，不碰鼠标 |
| Scarlet Hollow 多轴关系 / 外交声望系统 | 好感度要多轴 + 事件日志 + 迟滞，单条数值太假 | `Affinity` 四轴（友善/敬畏/尊重/信任）+ 事件 + 迟滞 |

## 3. 摄像头所有权规则（顶层设计，新增）

| 场景 | 谁拥有摄像头 | 说明 |
|---|---|---|
| 默认 | **玩家** | AI 绝不转玩家视角 |
| 玩家拉弓 / 弩 | **授权给 AI** | AI 旋转跟踪目标（R3），松手 / 切物品 / 急停立即归还 |
| 弹幕来袭 | 玩家（AI 不转头） | 弹幕威胁全部内部计算，见 R4/R5 |
| 落地后扫视 | 玩家（AI 用独立指针） | 见 R8 |
| 待命扫视 | 玩家（AI 用独立指针） | 原 IdleScan 由真实视角改为独立指针 |

**关键解耦**：感知不依赖真实摄像头。AI 沿独立指针做内部射线 / 范围查询即可收集
信息，真实视角只按上表授权流动。这样「AI 很忙」而「玩家鼠标纹丝不动」。

## 4. 需求详单

每条含：描述 / 动机 / 验收标准（可自动化）/ 涉及模块。

### 4.1 基础交互与操作

#### R1 状态静止
- **描述**：打开物品栏或玩家干别的事时，AI 不动。玩家开界面这件事对 AI 是可知、可预测的。
- **细节**：现有「原生界面只锁动作不冻决策」保留；新增 `humanActing → 运动通道强制弃权`：
  玩家按键期间 AI 连移动票都不投，但感知 / 决策 / 记忆照常跑。
- **验收**：玩家按住 W 期间 AI 不产生任何 FORWARD/STRAFE/JUMP 票；松手 1 拍内恢复。
- **模块**：Sensor(humanActing) → Machine(通道门控)

#### R2 高频组合操作
- **描述**：能同时「蹲下 + 进食」「蹲下 + 拉弓」等多键并行，胜任高频操作。
- **现状**：通道本就并行（CROUCH/USE/ATTACK 独立裁决），需要回归测试锁死不互斥。
- **验收**：SimTest 增加组合场景：蹲下票 + USE 票同拍都执行；蹲下 + RANGED 同拍有效。
- **模块**：Behaviors / Actuator（回归测试）

#### R3 战斗跟踪（唯一的「拉弓授权」场景）
- **描述**：玩家拉弓时，AI 把视角往左下、左右、后旋转跟踪对方，**一直保持旋转**。
- **细节**：目标 = 当前锁定敌对；用提前量角差（已有预测）；玩家松弓 / 切物品 / 急停
  立即归还摄像头。速率受控，不甩头。
- **验收**：拉弓期间真实 yaw 以受控速率逼近目标角差；松开后 1 拍内不再写视角。
- **模块**：新 TrackTarget 行为 + Actuator(视角写入门控)

### 4.2 弹幕与投射物（本次新增，重点）

#### R4 弹幕分级 —— 有的弹幕根本不用看
- **描述**：弹幕（箭 / 火球 / 三叉戟 / 雪球等）来袭时，**AI 不转摄像头去看**。
- **分级规则**（内部计算，零渲染）：
  - **A 级（需响应）**：弹道朝我、预计命中时间 TTI < 2s、命中点半径 < 1.5 格、无地形遮挡
  - **B 级（忽略）**：不朝我 / 太慢 / 太远 / 会被地形挡 / 命中点离我远
- **动机**：转头看弹幕 = 浪费摄像头所有权 + 打断当前任务。人被射时是「感觉到了」直接躲，
  不是先回头看一眼再躲。

#### R5 内部弹道预测 —— 不看、不找、不说，内部算完直接躲
- **描述**：AI 内部读弹幕实体的位置 + 速度，外推弹道（直线 / 抛物线两档模型），
  算最近接近点（CPA）与命中时间（TTI），据此直接产生**躲避票**（横移 / 后退 / 跳）。
- **静默性**：全程不转视角、不锁定目标、不渲染、**不刷聊天栏不播报** —— 内部算完就执行。
- **不影响正常操作**：躲避票权重「压过巡逻但压不过保命级威胁」；躲完自动回到原任务；
  玩家手动操作时照常让权。
- **验收**（全部可自动化）：
  1. 朝玩家飞的箭 → 产生 STRAFE/FORWARD 躲避票；真实视角 yaw/pitch 变化 ≤ 2°/拍
  2. 平行飞过 / 打不到的箭 → 零票、零视角变化
  3. 被墙挡住的箭 → 判 B 级，不响应
  4. 躲避期间 FORAGE/FOLLOW 的票不被清空（躲完继续）
  5. 玩家手动操作时照样让权
- **模块**：新 `neo.ProjectilePredictor` + 新 `Behaviors.DodgeProjectile`

### 4.3 感知与落地

#### R6 视野限制开关
- **描述**：提供「感知扩大」开关。关掉后 AI 的世界 = 玩家眼前的画面（视角锥内 + 近距），
  行为要在信息更少时**更聪明**（靠记忆 / 向量知识库补盲，而不是变傻）。
- **验收**：开关关闭时感知半径收缩到视角锥；未知变多时弃权规则照常生效（不猜）；
  VectorKB 召回「上次见过的目标方位」作为弱票。
- **模块**：Sensor + TritMod 开关 + VectorKB

#### R7 落地判断
- **描述**：从天而降时，第一步先看地面（独立指针向下）。判定地面高度：
  - 地面**太高**（落差大、会摔）→ 落地瞬间起跳卸力 / 有方块时提前搭脚
  - 地面**太低** / 正常 → 直接落地
- **验收**：构造下落场景：落差 > 3 格 → JUMP 票在触地前 2~4 拍出现；落差 ≤ 1 → 无跳票。
- **模块**：新 LandingWatch 行为 + Sensor(地面探针)

#### R8 落地收集信息（独立指针 + 收集信息分支）
- **描述**：落地后若处于高地，AI 用**自己的独立指针**四周旋转扫视收集信息；
  **绝不影响玩家鼠标指针**。
- **收集信息分支**：扫视结果先过一道分类 ——
  `LearningAutomaton.stateMachineEligible(输入种类数, 转移可观测, 可重复触发)`，
  **代码里记一行判定结果**（无神经元参与，纯启发式记录）：适合状态机的进状态机，
  不适合的进向量知识库。
- **验收**：落地扫视期间玩家视角零变化；扫视 360° 后记忆里出现新条目；
  每条候选信息有一行 `stateMachineEligible` 判定日志。
- **模块**：AiPointer + LandingWatch + LearningAutomaton.stateMachineEligible

### 4.4 行为细节与系统机制

#### R9 不死缠树 + 好感度 + 向量知识库
- **已有**：超时放弃目标、战斗时停挖。
- **新增**：
  - **多轴好感度 Affinity**：四轴（友善 / 敬畏 / 尊重 / 信任），事件驱动 + 时间衰减 +
    迟滞五阶段（敌对 / 警惕 / 中性 / 友善 / 忠诚）。影响：优先保护好感高者、
    规避「敬畏(怕)」高者、同类目标多次失败 → 降低该类目标优先级。
  - **向量知识库 VectorKB**：经验向量（敌类型 / 地形 / 行动结果）存档 + 余弦召回，
    用于熟悉度与「上次这类情况怎么处理的」。
- **验收**：被某实体伤害 → FEAR 上升 → 远离它；多次被助 → FRIEND/TRUST 上升 → 优先跟随；
  无互动时衰减回中性；KB 召回相似度在指标里可见。
- **模块**：neo.Affinity / neo.VectorKB + Behaviors 接线

#### R10 挖矿范围按角色（不写死）
- **描述**：挖矿 / 交互距离按当前角色实际能力读，**不做死限制**。
  默认表现同原版（约 3~4.5 格）；若装了「无限挖掘距离」类模组，它就该是无限制。
- **方案**：读 26.3 的 `player.blockInteractionRange()`（含模组加成），不硬编码 3。
- **验收**：读取值与游戏内实际可挖距离一致；装交互增强模组后读数随之变大。
- **模块**：Sensor

#### R11 跟随三记录 + 长按键锁定
- **描述**：跟随系统分别维护 **动物记录、玩家记录、指针记录** 三类目标档案。
  玩家先把准星（或独立指针）对准目标，**长按指定键** → 直接锁定该目标为跟随对象。
- **细节**：三类记录含 id / 类别 / 最近位置 / 好感度快照；长按 ≥ 15 拍生效（防误触）；
  锁定后 HUD 播报目标类别与名字。
- **验收**：长按不足不锁定；长按后 followId = 指针目标 id 且类别正确；目标死亡退回默认。
- **模块**：Sensor(FollowLedger) + TritMod(长按检测) + HUD

### 4.5 UI：鼠标驱动的黄盘

#### R12 环盘用鼠标操作，按键为辅助
- **描述**：环盘改**黄色**系；菜单打开时**鼠标移动即实时选中**对应扇区，
  **左键点击即确认**；方向键 / 数字键 / 回车保留为**辅助**输入，不是主要操作方式。
- **细节**：光标坐标 → gui 坐标换算（除以 guiScale）；按光标相对盘心的角度落扇区；
  中心 hub = 确认当前高亮。
- **验收**：光标划过选项时高亮实时跟随；鼠标点击确认与键盘确认等效；
  菜单打开期间 AI 让权。
- **模块**：TritHud（黄色重绘）+ TritMod(鼠标轮询 / 点击)

### 4.6 指标扩容（现状：指标太少）

WorldView 新增可观测指标，全部进 HUD / 日志，且每个至少 1 条测试断言：

| 组 | 指标 |
|---|---|
| 运动 | 速度向量、水平速度、垂直速度、下落速度、滞空拍数 |
| 地面 | 脚下地面相对高度、前方落差、高低地标志、落地预估伤害 |
| 环境 | 光照等级、雨 / 雷、天色暗度、生物群系、维度 |
| 威胁 | 最近敌距离 / 数量 / 类型、弹幕数量、最近弹幕 TTI、弹幕威胁级 |
| 目标 | 目标速度向量、提前量角差、遮挡、目标血量占比 |
| 社交 | 好感四轴值、关系阶段、最近事件、KB 召回相似度 |
| 资源 | 树 / 矿距离、挖掘进度、交互可达距离 |
| 系统 | 敌 / 资源感知半径、视野受限开关、单拍耗时(µs)、决策理由、票摘要 |
| 指针 | 独立指针 yaw / pitch、与真实视角的夹角 |
| 跟随 | 目标类别(动物/玩家/指针)、id、距离、长按锁定态 |

### 4.7 测试场景扩容（现状：场景太少）

- **战斗**：单敌近战脉冲 / 远距拉弓蓄满击发 / 边退边射风筝 / 绕圈侧移不站桩 /
  3+ 敌围攻边打边退 / 目标遮挡绕行 / 目标丢失重扫 / 残血撤退 /
  弹幕来袭不转头但横移 / 弹幕不命中零反应 / 蹲下同时拉弓 / 被围跳出包围圈
- **落地**：高空坠落先看地 / 落差 > 3 落地跳卸力 / 落差 ≤ 1 直接落 /
  落地原地独立指针扫视不动鼠标 / 落地即遇敌立即交战 / 落水
- **跟随**：锁玩家保持 4 格 / 锁动物 / 目标死亡退回默认 / 长按锁定 / 跟随中遇敌自保优先
- **采集**：挖完换目标 / 隔墙绕行 / 超时放弃 / 战斗停挖
- **社交**：被打 FEAR↑ 远离 / 被助 FRIEND↑ 优先跟随 / 无互动衰减回中性
- **UI**：鼠标高亮跟随 / 点击 = 键盘确认 / 菜单开 AI 让权
- **指标**：每个新指标至少 1 条断言（非空 / 范围 / 变化趋势）

## 5. 架构（神经符号三层）

```
感知 Sensor ──► WorldView（大量指标）
                    │
   ┌────────────────┼────────────────────┐
   │ Layer2 记忆/社交 │ Layer1 微神经元      │ Layer0 符号
   │ VectorKB 经验召回│ Neuron 软打分        │ K3 Machine
   │ Affinity 好感    │ LearningAutomaton    │ 投票→裁决→迟滞
   │ AiPointer 独立指针│ ProjectilePredictor │ Phase / Reason
   └────────────────┴────────────────────┘
                    │ 票（符号化，可解释）
              Behaviors（Dodge / Landing / Track / ...）
                    │
          Actuator（摄像头所有权门控，见 §3）
```

- **Layer 0 符号层**：现有 K3 状态机原样保留 —— 时序、安全、弃权规则是底座。
- **Layer 1 微神经元层**：每个行为配一个 3~8 输入的固定微感知机 + 学习自动机在线调权。
  无反向传播、无 GPU，单拍 O(n) 浮点。
- **Layer 2 记忆/社交层**：向量知识库（经验召回）+ 多轴好感度（关系）+ 独立指针（自有视角）。
- **弹幕内部预测**属于 Layer 1：纯数值外推，产出是「躲避票」，天然可解释、可测试。

已落地（未接线、未提交）：`com.bfxh.trit.neo.{Neuron, LearningAutomaton, VectorKB, Affinity, AiPointer}`
—— 纯 Java 零依赖，`test.py` 可直接编译测试。

## 7. 开放问题（实现前需确认）

1. 弹幕抛物线外推：26.3 客户端能否读到弹射物重力分量？箭有重力、火球近似直线
   → M3 用「直线 / 抛物线」两档模型兜底，按实体类型选。
2. `blockInteractionRange()` 的准确签名需 javap 反查（26.3 API 漂移是惯例）。
3. 鼠标坐标 → gui 坐标的换算需实机确认 guiScale 语义（M5 第一件事）。
4. 原 IdleScan 从「转真实视角」改为「转独立指针」后，玩家在屏幕上看不到 AI 在看哪
   → 需要在 HUD 上画一个极淡的独立指针标记（不抢焦点），待定。
